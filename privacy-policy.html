Overview

This privacy policy covers the Gmail Categorizer application and the website marlsantos.com, operated by Marlon Santos ("I", "me"). Contact: marlonsantos.au@gmail.com.

1. Gmail Categorizer Application

The Gmail Categorizer is a personal automation tool that connects to my own Gmail account to organize my inbox.

  • Data accessed: Email metadata (subject lines, message snippets, label assignments) from my own Gmail account via the Gmail API, using the gmail.modify scope.
  • What it does: Reads subject lines and snippets of uncategorized emails, sends them to the Google Gemini API for classification, and applies category labels within Gmail.
  • Data storage: Gmail data is not stored, transferred, or archived anywhere outside my own Gmail account and the application's local authentication token. Email content is transmitted only to Google's Gemini API for classification and is not retained by the application.
  • Data sharing: No Gmail data is sold, shared with third parties (other than Google's own APIs), or used for advertising. No data is used to train machine-learning or AI models.
  • Human review: No humans review Gmail data. Processing is fully automated, initiated only by me.
  • Access revocation: Access can be revoked at any time via your Google Account settings (Privacy & Personalization → Security → Third-party apps with account access).

2. Website (marlsantos.com)

  • Analytics: This site uses Google Analytics to collect anonymous usage statistics (pages visited, approximate location, browser type). No personally identifying information is collected or stored by me.
  • Cookies: Google Analytics sets cookies solely for aggregate analytics purposes.
